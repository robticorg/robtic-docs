---

**Files** shows your app's folder. Click a file to open it in the editor, change it and press **Save** — then restart
the app. Drag a whole folder in to upload it.

![The code editor](/shots/hosting/editor.webp)

## SFTP

Prefer your own editor? Add **SFTP** to the app in its workspace: Robtic creates a login for it. Connect with any SFTP
client (FileZilla, WinSCP, VS Code SFTP) using the address, port, username and password shown.

> **Important** The password is shown only once, right after the login is made. Copy it then.
