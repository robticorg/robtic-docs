Robtic Hosting runs your code for you: a Discord bot, a website, an API. Everything lives in the **[panel](https://robtic.org/panel)** —
start and stop your apps, edit files, read logs, add a database, take backups.

![Workspaces in the panel](/shots/hosting/workspaces.webp "A workspace: apps, databases, backups and schedules on one canvas")

## What you get

| | |
|---|---|

| [Live console](/hosting/console) | Start, stop, restart, type commands, read logs as they happen. |
| [Files & editor](/hosting/files) | Edit code in the browser, upload folders, or use SFTP. |

| [Secrets](/hosting/secrets) | Environment variables, encrypted. |
