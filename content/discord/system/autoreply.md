Auto reply answers messages automatically: "when someone writes *hello*, reply *Welcome!*". Up to 25 rules per server.

![Auto reply](/shots/system/autoreply.webp)

## Add a rule

1. Open **Robtic System → Auto reply** and press **New rule**.
2. Write the **trigger** — the words that start it. Choose *contains*, *exact* or *starts with*.
3. Write the **reply**. Add up to 3 replies (tabs **1 | 2 | 3**) and the bot picks one at random.
4. Optional: reply to the message, react with an emoji, attach files, limit it to some channels.
5. **Save**.

> **Tip** Use **Advanced** for regex triggers, cooldowns and active hours. Triggers can't be the same as a [shortcut](/discord/system/commands) phrase.
