Inside a ticket, staff use slash commands or typed commands with your prefix.

![Ticket commands](/shots/ticket/commands.webp "Robtic Ticket → Commands: turn commands on or off and add your own words")

| Command | |
|---|---|
| `/close [reason]` | Close the ticket |
| `/claim` | Claim it (again to unclaim) |
| `/rename <name>` | Rename the channel |
| `/add` · `/remove <member>` | Add or remove someone |
| `/transfer <member>` | Give the ticket to another staff member |
| `/transcript` | Save the transcript now |
| `/come` | Call the owner back with a DM |
| `/sleep` | Remind the owner and start the auto-close countdown |

## Change the prefix

The prefix for typed commands (default `!`, up to 5 characters) can be changed in two places:

- **Dashboard:** Robtic Ticket → Settings → **Command prefix**.
- **In Discord:** `/prefix ?` or `!prefix ?` (needs **Manage Server**). Mention the bot to see the current prefix.
